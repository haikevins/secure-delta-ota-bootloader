## Generate a fresh report

```bash
make benchmark TOOLCHAIN=gcc
```

Generated output is written below `dist/benchmark/` and is intentionally not the same thing as the checked-in reference.

## Interpretation rule

Portable claims are the fixed memory budgets, measured footprint within those budgets, signed/raw delta savings, artifact fit, and recorded HIL scenario count. Wall-clock timing depends strongly on host CPU, storage, Python/toolchain versions, and should be reported together with its environment rather than treated as a device constant.
