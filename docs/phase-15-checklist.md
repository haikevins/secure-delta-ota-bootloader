- [x] Full SDOT release artifact generated.

- [x] Release directory is immutable.
- [x] Release manifest contains sizes, CRC32, SHA-256 and HTTPS URLs.
- [x] Release manifest has detached ECDSA-P256/SHA-256 signature.
- [x] Private signing key is rejected inside the repository.
- [x] Private signing key permission check is enforced on POSIX.
- [x] Public key only is copied into release output.

- [x] Server requires TLS for firmware serving.
- [x] Server has no directory listing/arbitrary repository file serving.
- [x] Server selects exact-base delta, otherwise full fallback.
- [x] MQTT command remains Phase-11 schema compatible.

- [x] ESP32 artifact limit matches 128 KiB STM32 Incoming partition.
